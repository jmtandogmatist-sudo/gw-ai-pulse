## 二、632 字段的时间属性（为什么有些块"不动"）

```
   字段                写入者              节奏          今天实测
  ────────────────────────────────────────────────────────────────────
   mainline         日报 skill           每天 1 次      09:28
   brief            ★ 日报 + 采集器      每天 3~4 次    14:19  ← 已修
   picks            日报 skill           每天 1 次      09:28
   lead             ★ 日报 + 采集器      每天 3~4 次    14:19  ← 已修
   curated          日报 skill           每天 1 次      09:28
   community        日报 skill           每天 1 次      09:28
   tracking         日报 skill           每天 1 次      （空）
   ────────────────────────────────────────────────────────────────────
   radar            采集器               每天 2 次      14:19  ← 已改 12:00/16:00
   radar_updated_at 采集器               同上           14:19
   radar_next_at    采集器               同上           16:00
   ────────────────────────────────────────────────────────────────────
   topics           主题档案 skill       每周           缺失
   stance           技术雷达 skill       每季度         缺失
  ────────────────────────────────────────────────────────────────────
   updated_at       日报 skill           每天 1 次      09:28（日报侧时间戳）
   brief_updated_at ★采集器新增          每天 2 次      14:19
```

★ = 2026-11-16 本次改动新增

**设计原则**：采集器只碰 `radar*` + `brief*` + `lead` + `brief_updated_at`，其余字段原样保留。四套程序（采集器 / 日报 / 主题档案 / 技术雷达）写同一个帖子但互不覆盖。
