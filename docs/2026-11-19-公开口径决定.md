## 3 被否掉的原方案：删除「机器可读数据」块

原理由是「它把 `us` 等内部字段结构化暴露给公网」。**这个前提是错的**：
`render.topic_body` 生成该块时就排除了 `title` / `summary` / `us`
（见 `collector/render.py` 的 machine 推导行），块里只有
`signal_id / event_key / domain / questions / topics / relevance / cred / review / 日期 / sources` 等编排字段。

而且它有两个活着的下游：

- `skills/ai-topic-dossier/scripts/forum.py`：`parse_machine()` 从信号帖里取这些字段建主题档案；
- `skills/ai-radar-daily/scripts/mark_reviewed.py`：改写块里的 `review` 为 `reviewed`
  （注意：它同时依赖 `[wrap=ais-us]` / `**对金风**` 段落，而现在的渲染已改成
  `[details="AI 研判…"]`，这条替换逻辑其实已经失效——日报 skill 停用后没人发现）。

**结论**：删块 = 弄坏主题档案 + 零安全收益。真要删，得先给 dossier 做迁移。
