# Wind Chief Expert（核心评估框架参考）

- **证据阶梯 T0–T4**：T0 法定标准与政府政策（IEC/ISO/国家能源政策）> T1 权威行业基准（GWEC/IEA/IRENA/DNV/经审计年报）> T2 同行评审与一手技术发布（NREL/DTU/厂商官方）> T3 行业媒体（Windpower Monthly/Recharge/OffshoreWind/Reuters 等信号源）> T4 未证实宣称与厂商公关（须标注待第三方验证）。
- **物理与工程边界**：不混淆相关与因果；区分陆上/海风浅水/深远海浮式及气候工况；不脱离基础/船机/电网承载力谈大型化。
- **政策与贸易因果传播链**：政策变化 → 市场准入/碳足迹门槛 → 项目 LCOE 与 IRR → 开发商投资决策 → 风电整机厂 → 一二级零部件供应链 → 技术路线与出海对冲策略。
- **证据与缺口纪律**：所有确定性数据须带来源与日期；两家 T1 数据分歧时并列说明口径差异；缺失实证数据时显式声明待验证。
